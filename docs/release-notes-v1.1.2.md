## Pi Pairing v1.1.2

A documentation release: the README now leads with the philosophy, the features,
and a clear path to running Pi Pairing on your own machine.

### What changed

- **New README structure**
  - Philosophy — the six principles behind the method, plus what the tool
    deliberately refuses to be.
  - Features — a scannable list of what the tool does.
  - The loop — what happens at each of the eight steps.
  - Install — Pi package, clone, and Windows paths, with requirements.
  - Use it on your own system — the daily workflow from dashboard to
    `/skill:pi-pairing` to a finished session.
  - CLI reference, data and privacy, configuration, troubleshooting,
    uninstall, development, roadmap, and contributing.
- **New screenshots** — the dashboard in dark mode is now the hero image, with a
  light-mode version alongside it. Both use synthetic demo data so no private
  project information is published.

### Install

```bash
pi install github:brando008/pi-pairing
```
